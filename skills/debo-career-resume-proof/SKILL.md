# DEBO Career Evidence-to-Resume v1.0 (STAGED)

## Trigger
A specific target role or request for a career master résumé, cover letter, proposal, portfolio case study or interview pitch.

## Contract
1. Recover existing résumé source, work-history facts, DEBO build receipts and owner-approved public portfolio evidence. Distinguish self-reported, verified, inferred and missing evidence.
2. Record company, role, chronology, actual tasks, tools personally used, defensible metrics and source before drafting. Never invent employers, degrees, dates, certifications, leadership titles or business outcomes.
3. For each project explicitly classify PLANNED, BUILT, TESTED, OWNER_APPROVED and LIVE. A privately tested mockup is not a shipped client platform.
4. Produce an ATS-friendly one- or two-page résumé with clear headings, no invented keywords and relevant evidence-backed examples. Keep the original master résumé unchanged.
5. For freelance proposals answer client-specific scope, outcomes, deliverables, schedule, risks and questions. Avoid copying client prompts verbatim; no impersonation or secret customer records.
6. Keep unknown items as [VERIFY] privately, and never include unresolved placeholders in an externally submitted final document.
7. Run factual QA: every factual bullet maps to source or confirmed owner assertion; dates and claims consistent; contact data intentionally included; link active and use rights checked; promised skills are defensible.
8. Save revised résumé as a versioned derived artifact in the existing career workspace. All submissions, public posts, platform profile updates and outreach require specific approval.

## Output
ROLE / FIT / EVIDENCE USED / DRAFT / UNCERTAINTY / QA RESULT / EXACT NEXT ACTION and checkpoint timestamp with timezone.
