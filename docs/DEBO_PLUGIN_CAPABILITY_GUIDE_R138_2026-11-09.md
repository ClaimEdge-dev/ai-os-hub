## Read this first

- **Directory installed** = plugin directory returned an installed flag for that exact app. **Tool exposed** = a callable operation is present in this conversation; that does not prove the appropriate business account, login, editor seat, or permissions. **Owned private** = private ChatGPT plugin record exists in the owner's plugin creator account; its runtime action still needs a task-specific test.
- Every entry explains **what it does** and **where it helps**. Features and availability can change. The owner read names aloud, so ambiguous transcriptions stay unresolved rather than being made up.
- Use **one DEBO Core** with project-specific adapters, and source rights: GitHub code; Notion knowledge; Drive evidence; dashboard controls; Neon current DEBO-05 database; other projects retain existing CRMs and backends. Avoid a second master or blind bulk connection.

## How DEBO recommends a plugin while working

For each relevant task give: **(1) what it is**, **(2) 2–4 useful features**, **(3) when/why to use it now**, **(4) example result**, **(5) cost, sign-in and permission requirements**. Example: *For a protected DEBO dashboard release, Vercel hosts the site and enforces sign-in; GitHub versions the code and runs tests; Neon stores private task data. We can test the editor against a private preview without making the data public. Verify owner login and pass security checks first.*

**Maintenance:** use the existing enabled weekly DEBO System Scout (Monday) to inspect meaningful plugin changes. Also recheck the directory at task time or after a reported install/permission change; the Scout is not real-time. Store a verified delta in the existing Tool Selection Register/Notion control page, and report unsaved changes accurately. Don't automatically install apps, expand permissions, spend money or connect unrelated business data.

**Status labels:** DIRECTORY_INSTALLED | TOOL_EXPOSED | OWNED_PRIVATE | USER_REPORTED | UNRESOLVED | ACCOUNT_VERIFIED | WORKFLOW_TESTED. A plugin being listed is not proof that its specific actions are safe or complete.
