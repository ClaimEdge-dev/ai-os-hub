# Universal Filing System
Canonical folder template (create only after checking existing project folders):
00_START-HERE
01_COMMAND-CENTER
02_BRAND-ASSETS
03_TEMPLATES
04_CLIENTS-AND-JOBS
05_OPERATIONS
06_FINANCE-INVOICES-REVENUE
07_SALES-MARKETING
08_WEBSITE-CRM-SOFTWARE
09_EVIDENCE-REPORTS
10_LEGAL-COMPLIANCE
11_SKILLS-AUTOMATIONS
12_TESTS-RELEASES
13_APPROVALS-DECISIONS
90_INBOX-TO-SORT
99_ARCHIVE
Naming: PROJECTID__TYPE__SUBJECT__YYYY-MM-DD__vMAJOR.MINOR__STATUS.ext
Example: JCT__INVOICE-TEMPLATE__STANDARD__2026-10-22__v0.1__DRAFT.docx
Keep immutable originals and a manifest linking the latest approved version. Never archive by age alone; verify supersession, dependencies, legal holds and retention rules. Index fields: artifact_id, project_id, title, path, version, created_at, updated_at, status, owner, sensitivity, source, supersedes, approved_by, evidence_url.
