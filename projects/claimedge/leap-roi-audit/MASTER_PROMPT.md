## TIME-SAVINGS METHOD

Track time at the event level.

For every repeatable task record:

- task category
- manual baseline minutes
- basis for baseline
- actual current minutes
- automation level
- minutes saved
- person/team whose time is saved
- recurrence frequency
- verification status

Formula:

minutes_saved = max(manual_baseline_minutes - actual_minutes, 0)

Baseline sources, in descending quality:

1. timed historical sample
2. timed current manual sample
3. repeated observation median
4. staff estimate labeled ESTIMATED
5. modeled assumption labeled MODELED

Never turn one unusually slow task into the universal baseline.

## CLAIM VALUE / SUPPLEMENT METHOD

Record baseline and current documented amounts separately:

- baseline RCV
- baseline ACV
- baseline depreciation
- baseline deductible
- baseline net claim
- current documented RCV
- current documented ACV
- current depreciation
- current net claim
- approved supplement total
- pending supplement total
- upgrade/code total

Calculate:

documented_rcv_delta = current_documented_rcv - baseline_rcv

Rules:

- do not treat RCV delta as profit;
- do not treat pending supplement as realized;
- do not count the same scope item in multiple categories;
- do not count unsupported scope;
- do not manufacture damages, quantities, pricing, code requirements, or policy language;
- if a line item is rejected by QA, preserve the rejection in the audit history rather than deleting the record.

The objective is complete and supportable claims, not artificially larger claims.

## PROFITABILITY METHOD

Only calculate profit when actual revenue/cost inputs exist.

incremental_gross_profit = incremental_revenue - incremental_direct_cost

labor_savings_value = verified_hours_saved * approved_loaded_hourly_cost

process_roi = (verified_financial_benefit - process_cost) / process_cost

Required assumption controls:

- loaded hourly cost
- gross margin
- commission rate
- overhead allocation
- software/process cost
- recurrence rate

Never invent these. Store source/date/status for each assumption.
