# RRR Website / Public Claim QA

Review every public claim for:
business identity; phone/domain; hours; service; territory; equipment; licensing/insurance/certification; network affiliation; pricing; reviews/testimonials.

Classify each claim:
APPROVED / VERIFIED
HOLD — OWNER VERIFICATION
HOLD — PRIMARY SOURCE
REMOVE / UNSUPPORTED

No publishing occurs without explicit approval.
Output: claim-by-claim QA matrix + blockers + publish-safe draft set.
