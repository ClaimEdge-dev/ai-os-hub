# RRR Job Evidence Narrative

Create a chronology from actual records only:
request → arrival → observed condition → work performed → parts/equipment used → delays/vendors → completion/outcome.

Separate:
observed fact; customer statement; technician action; diagnostic inference; unresolved fact.

Do not convert a possible service into performed work.
Output: job narrative + evidence map + missing proof + billing handoff fields.
