# RRR Service Capability Register

For each service/capability record:
service; vehicle/equipment class; owned/available equipment; geographic scope; hours/availability; source; owner approval; evidence state; restrictions.

Never infer a capability from JCT, a competitor, a logo, or a generic roadside-repair category.
Unknown equipment/capability remains TBD/HOLD.
Output: capability register + public-claim-safe subset + verification gaps.
