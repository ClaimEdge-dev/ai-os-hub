# RRR Rate Authority Manager

A past invoice, competitor rate, or market benchmark is not automatically RRR rate authority.

For each rate:
service; unit basis; customer/account type; amount; effective date; source; owner approval; exception rules; supersession.

If approved authority is missing or conflicting, return RATE TBD / OWNER APPROVAL.
Never publish or quote unsupported rates.
Output: rate register + gaps + exact authority required.
