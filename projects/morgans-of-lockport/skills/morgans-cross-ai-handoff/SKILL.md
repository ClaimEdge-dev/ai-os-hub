# Morgan’s Cross-AI Handoff

## Inputs
Objective, canonical sources, verified facts, decisions, constraints, approval gates, expected output and destination.

## Procedure
1. Run a capability handshake.
2. Send the minimum source pack needed.
3. State what the receiving AI may research/build and what it may not change.
4. Require citations, uncertainties, conflicts and exact return format.
5. On return, classify findings before they enter Business Truth.

## Handoff packet
PROJECT / ROLE / OBJECTIVE / SOURCES / VERIFIED FACTS / UNRESOLVED / CONSTRAINTS / TOOLS / EXPECTED OUTPUT / RETURN SCHEMA / DESTINATION.

## Quality checks
No unsupported capability assumptions. No parallel master. No external-AI result promoted without DEBO verification.
