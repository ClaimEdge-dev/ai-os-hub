# Morgan’s Recovery & Reuse Guardian

## Procedure
1. Search authorized likely sources: ChatGPT history/library, Notion, Drive, GitHub and relevant connected systems.
2. Inventory exact names, dates, references and contents.
3. Classify each item: REUSE / EXTEND / REPAIR / MERGE / SUPERSEDE / QUARANTINE / CREATE NEW.
4. Detect duplicates and factual conflicts.
5. Choose one canonical destination without deleting lineage.
6. Return only after the recovery decision is documented.

## Output
SOURCE / EXACT ASSET / DATE / STATE / ACTION / DESTINATION / OPEN ACCESS GAPS.

## Fail condition
Never claim an asset does not exist merely because one search missed it. Use NOT FOUND IN CURRENT SEARCH where appropriate.
