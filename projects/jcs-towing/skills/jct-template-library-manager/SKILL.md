# JCT Template Library Manager
Recover existing templates before creating new ones. Maintain template ID, category, title, purpose, owner, source file, current version, status, required fields, linked workflow and superseded version. Prefer one canonical template per purpose. Merge duplicates carefully; never delete or destructively merge without approval. Route files into the existing JCT Drive structure.
