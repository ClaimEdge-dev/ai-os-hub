# JCT CRM Workflow Automation
Automate only after data model and trigger are defined. Preferred flow: CALL → LEAD → DISPATCH → JOB → EVIDENCE → INVOICE → QA → PAYMENT → FOLLOW-UP. Use approval gates for outbound messages, pricing exceptions, publishing and destructive changes. Log automation source, trigger, action, owner, failure state and manual fallback.
