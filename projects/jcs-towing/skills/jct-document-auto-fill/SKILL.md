# JCT Document Auto Fill
Use only approved/current templates and verified source fields. Map source → field explicitly. Never guess VIN, claim, times, mileage, operator, equipment, rates, authority, services performed or signatures. Mark unresolved required fields TBD/HOLD. Preserve source references and template version. Generated documents remain draft until applicable QA/approval gates pass.
