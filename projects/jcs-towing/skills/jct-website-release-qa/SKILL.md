# JCT Website Release QA
Recover the current website source, approved brand, public business truth and prior QA first. Check phone/contact data, services, service area, hours, claims, rates, forms, CTA paths, mobile layout, accessibility basics, metadata, local SEO basics, analytics/call tracking, privacy/security exposure and broken links. Classify findings BLOCKER / HIGH / MEDIUM / LOW. Never publish or make unsupported public claims. Release requires explicit approval.
