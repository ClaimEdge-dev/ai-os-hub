# JCT Website CRM Sync
Use jct-crm-data-model as schema authority. Map each web form/call event to Lead/Call, Contact, service need, vehicle, location, source/UTM, timestamp, consent, urgency and status. Deduplicate before creating records. Preserve raw submission evidence. Never silently overwrite verified CRM data. External messaging and production deployment remain approval-gated.
