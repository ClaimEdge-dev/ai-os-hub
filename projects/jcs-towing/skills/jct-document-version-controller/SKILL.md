# JCT Document Version Controller
Use JCT_[CATEGORY]_[DOCUMENT-NAME]_vMAJOR.MINOR_YYYY-MM-DD naming for finished reusable artifacts. Track DRAFT / REVIEW / APPROVED / SUPERSEDED. Never overwrite an APPROVED artifact with materially changed content; create a new version and link predecessor/successor. Preserve historical versions in JCT 99/archive as appropriate. Destructive deletion or merge requires approval.
