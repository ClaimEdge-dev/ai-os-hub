# JCT Source Verification Engine
For each material claim record source, authority, jurisdiction, publication/effective date, access date, claim supported, conflicts and confidence. Prefer primary/current sources. Use VERIFIED / LIKELY / UNRESOLVED for current research and preserve JCT business-truth status separately. Do not silently resolve conflicting sources. Expiring facts receive a review date. This skill supports all research-heavy JCT workflows.
