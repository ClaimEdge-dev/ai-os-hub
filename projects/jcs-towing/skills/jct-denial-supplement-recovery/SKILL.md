# JCT Denial & Supplement Recovery

## Trigger
Use when an insurer, commercial payer, or adjuster reduces, denies, bundles, or questions a towing/recovery charge.

## Workflow
1. Recover invoice, job evidence, rate authority, payer explanation, and prior communications.
2. Map each disputed line to work performed, evidence, rate source, and denial reason.
3. Identify documentation defects or non-duplicative support.
4. Build corrected/supplemental itemization when justified.
5. Draft reconsideration or supplement response; external send requires approval.
6. Track final allowed/paid outcome back to Insurance Payment Evidence.

## Rules
- Never add an unperformed service.
- Never conceal duplicate billing.
- If support is insufficient, mark HOLD/NEEDS EVIDENCE instead of arguing around it.

## Output
Dispute matrix, evidence gaps, supplement/reconsideration draft, and payment-tracking update.
